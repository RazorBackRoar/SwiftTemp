# Contributing to Swifter

Thank you for your interest in contributing to Swifter!

## Development Guidelines

1. **Swift 6 & SwiftUI:** Use modern, idiomatic Swift and SwiftUI APIs.
2. **Tests First:** All engine and business logic changes must be accompanied by unit tests in `Tests/SwifterTests`.
3. **Zero Dependencies:** Avoid adding external 3rd-party dependencies unless strictly necessary.
4. **Run Tests:** Ensure `swift test` passes cleanly before opening a pull request.
